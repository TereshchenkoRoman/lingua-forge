## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend updating the configuration to enable type-aware lint rules:

```js
export default defineConfig([
  globalIgnores(['dist']),
  {
    files: ['**/*.{ts,tsx}'],
    extends: [
      // Other configs...

      // Remove tseslint.configs.recommended and replace with this
      tseslint.configs.recommendedTypeChecked,
      // Alternatively, use this for stricter rules
      tseslint.configs.strictTypeChecked,
      // Optionally, add this for stylistic rules
      tseslint.configs.stylisticTypeChecked,

      // Other configs...
    ],
    languageOptions: {
      parserOptions: {
        project: ['./tsconfig.node.json', './tsconfig.app.json'],
        tsconfigRootDir: import.meta.dirname,
      },
      // other options...
    },
  },
])
```

You can also install [eslint-plugin-react-x](https://github.com/Rel1cx/eslint-react/tree/main/packages/plugins/eslint-plugin-react-x) and [eslint-plugin-react-dom](https://github.com/Rel1cx/eslint-react/tree/main/packages/plugins/eslint-plugin-react-dom) for React-specific lint rules:

```js
// eslint.config.js
import reactX from 'eslint-plugin-react-x'
import reactDom from 'eslint-plugin-react-dom'

export default defineConfig([
  globalIgnores(['dist']),
  {
    files: ['**/*.{ts,tsx}'],
    extends: [
      // Other configs...
      // Enable lint rules for React
      reactX.configs['recommended-typescript'],
      // Enable lint rules for React DOM
      reactDom.configs.recommended,
    ],
    languageOptions: {
      parserOptions: {
        project: ['./tsconfig.node.json', './tsconfig.app.json'],
        tsconfigRootDir: import.meta.dirname,
      },
      // other options...
    },
  },
])
```













# Django REST + React Frontend

Production-ready React + Vite + TypeScript frontend scaffold for a Django REST Framework backend.

## Key features

- React 18 + Vite + TypeScript (strict)
- React Router v6 with lazy routes and protected routes
- TanStack Query for server state and caching
- Axios with centralized instance and refresh token flow
- Zustand for small client-side auth UI state (chosen for simplicity and minimal boilerplate)
- React Hook Form + Zod for form handling and validation
- i18n-ready folder structure
- Vitest + React Testing Library for unit tests
- Playwright for E2E tests (example flows)
- ESLint (Airbnb), Prettier, Husky + lint-staged
- Sentry placeholder for observability
- CI pipeline (GitHub Actions) for lint, typecheck, tests, build

## Why Zustand (short note)

Zustand is chosen for the small auth UI store because it is lightweight, has minimal boilerplate, and integrates well with React hooks. For larger global state needs, Redux Toolkit can be added later; the architecture keeps feature modules isolated so switching is straightforward.
